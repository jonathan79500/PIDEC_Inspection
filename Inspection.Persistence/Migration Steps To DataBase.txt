1- Install Package "Microsoft.EntityFrameworkCore.tools"
2- run this Command: dotnet tool install --global dotnet-ef
2- Package Manager Console : dotnet ef migrations add <Migration_Name> --project Inspection.Persistence
3- Package Manager Console : dotnet ef database update <Migration_Name> --project Inspection.persistence


For Update DataBase based on New Changes in Entities
1- Package Manager Console : dotnet ef migrations add <New_Migration_Name> --project Inspection.Persistence
2- Package Manager Console : dotnet ef database update <New_Migration_Name> --project Inspection.persistence
